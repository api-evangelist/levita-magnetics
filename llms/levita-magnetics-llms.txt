# Levita Magnetics

> Medical device company in Mountain View, California (with an office in Santiago, Chile) that
> develops Magnetic Surgery: the Levita Magnetic Surgical System, where an external magnet on the
> patient's skin controls a shaftless detachable retractor for reduced-port laparoscopic procedures,
> and the FDA-cleared MARS (Magnetic-Assisted Robotic Surgery) platform launched in 2023.

Levita sells regulated surgical hardware and its embedded control software to hospitals and surgical
centers. As of 2026-08-25 it operates NO public developer program: there is no developer portal, no
API documentation, no SDK, no public repository, and no machine-readable API contract on any host it
controls. This file is generated by API Evangelist from the public company surface, not published by
Levita Magnetics.

## Developer surface

None published. Verified 2026-08-25 by direct probe:

- No OpenAPI/Swagger: /openapi.json, /swagger.json, /api-docs, /docs all return 404 on www.levita.com and www.magneticsurgery.com.
- No GraphQL: /graphql returns 404.
- No MCP server and no A2A agent card: /.well-known/agent-card.json and /.well-known/agent.json both 404.
- No /.well-known/ documents of any kind on either host (see well-known/levita-magnetics-well-known.yml).
- No GitHub organization (levita, levita-magnetics, levitamagnetics all 404 on the GitHub API).
- No first-party packages on npm, PyPI or any other registry. The `levita-js` npm packages are an
  unrelated 3D tilt/parallax library, not Levita Magnetics.
- The only machine-readable endpoint on www.levita.com is /wp-json/, the stock WordPress REST API of
  the marketing CMS (namespaces wp/v2, yoast/v1, contact-form-7/v1, divi/v1, wpjm-internal/v1 and
  other plugin routes). It is content-management boilerplate, not a Levita product API, and is
  deliberately NOT cataloged as one.
- The MARS platform's internal connectivity is RTI Connext (the OMG DDS standard), per RTI's own
  customer announcement — an embedded real-time bus inside the robot, not an externally callable API.
